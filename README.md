# 全能外挂引擎

这是一个 SillyTavern 浏览器扩展。它提供一个可编辑的外挂资料库，让用户按类型和作品选择外挂，并在生成前把选中的外挂作为临时附加设定加入上下文。

## 当前包含

- 能力、功法、技能、系统、道具五种分类；
- 作品筛选和关键词搜索；
- 类型分类与作品分类可以同时启用，筛选条件会叠加生效；
- 条目分页，默认每页显示 6 条；
- 内置条目可直接编辑或删除；
- 用户可以通过模板新建条目，也可以编辑和删除自己创建的条目；
- 用户条目、修改覆盖和删除记录保存到 `extensionSettings.ability-fusion-engine`，不会改写仓库里的内置数据文件；
- 加入、取消、只看已选；
- 选择保存到 `extensionSettings.ability-fusion-engine`；
- 酒馆底部扩展快捷入口弹出列表中的菜单项；
- 点击菜单项后打开独立面板；
- 总注入开关；
- 生成前通过 `generate_interceptor` 插入附加设定；
- `data/abilities.json` 可继续扩充的本地数据格式；
- 结构化外挂详情与可选阶段变化；
- `ABILITY-DETAIL-GUIDE.md` 提供字段填写说明和可复制的详情撰写提示词；
- 内置小说、动漫能力资料，条目带来源标签。

## 安装位置

把本目录中的文件放入 SillyTavern 的 `public/scripts/extensions/third-party/ability-fusion-engine/` 文件夹，并在酒馆扩展管理器中启用。当前没有自动安装动作，也没有要求服务器插件。

## 使用

1. 打开 SillyTavern 聊天页面。
2. 点击底部原有的扩展程序快捷入口。
3. 在弹出的扩展列表里点击“全能外挂引擎”。
4. 在面板里搜索或按分类、作品筛选。
5. 点击“新建条目”打开编辑器；可以直接点击“载入设定模板”，再修改名称、作品、标签、简介、核心效果、使用条件、限制和可选阶段。
6. 在条目卡片上使用“编辑”或“删除”；内置条目的修改会保存为用户覆盖，删除只对当前用户隐藏原始条目。
7. 点击“加入外挂”，再打开右上角“注入开关”。
8. 下一次生成时，外挂会临时加入上下文；取消选择或关闭开关后，后续生成不再加入。

## 数据格式

每条记录至少需要：

```json
{
  "id": "stable-id",
  "category": "ability",
  "name": "名称",
  "work": "作品名",
  "source": { "status": "verified | reference | unverified | custom", "label": "来源说明" },
  "tags": ["标签"],
  "description": "面板中的短说明",
  "effects": ["具体效果"],
  "requirements": ["使用条件"],
  "limits": ["限制、失败条件或代价"],
  "stages": []
}
```

`category` 只能使用 `ability`、`cultivation`、`skill`、`system`、`item`（道具）。

面板内置模板见 `data/ability-template.json`。`id` 只在直接维护 JSON 文件时需要稳定填写；面板新建条目会自动生成用户条目 ID。生成前会从外挂名称、作品、简介、效果、条件、限制、阶段和来源标注自动整理完整资料，不再使用 `prompt` 字段。

用户编辑不会直接修改 `data/abilities.json`：

- 自定义条目保存到 `customAbilities`；
- 编辑内置条目保存到 `abilityOverrides`；
- 删除内置条目保存到 `deletedIds`；
- 选择状态仍保存到 `selectedIds`。

升级后，扩展读取设置时会删除自定义条目和内置覆盖中的旧 `prompt` 字段并保存；旧字段不再参与注入。内置外挂详情本身不会在升级时自动重写。

## 当前未验证边界

- 尚未在用户的真实 SillyTavern 实例中安装和启用；
- 扩展列表菜单项依赖酒馆页面的 `#extensionsMenu` / `.extensionsMenu` 容器（宿主 DOM，非稳定公共 API）；
- 当前按 SillyTavern 的生成拦截器约定，在最新用户消息之前加入附加系统消息；尚未确认目标实例的实际消息顺序和清理时机；
- 这不是精确的内部“用户设定描述后”栏位控制，具体排序需要真实宿主确认；
- 当前内置资料是第一批整理结果，不代表覆盖所有作品、改编版本或所有能力条目；来源链接用于回查，不把搜索摘要当成原作全文。

## 安全边界

扩展不访问账号密钥，不发起外部资料请求，不调用保存聊天记录的接口。它会在生成前改动拦截器收到的消息数组，并在生成结束/回复到达事件尝试移除该临时消息；是否完全不进入持久聊天记录尚未经过真实宿主验收。扩展不自动安装其他扩展。真实安装、发布和资料收集不包含在本轮授权内。
