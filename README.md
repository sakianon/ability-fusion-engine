# 外挂能力聚合引擎

这是一个 SillyTavern 浏览器扩展的第一版。它提供一个资料面板，让用户按类型和作品选择外挂，并在生成前把选中的外挂作为临时附加设定加入上下文。

## 当前包含

- 能力、功法、技能、系统四种分类；
- 作品筛选和关键词搜索；
- 加入、取消、只看已选；
- 选择保存到 `extensionSettings.ability-fusion-engine`；
- 输入框左侧快捷入口按钮和独立弹层面板；
- 总注入开关；
- 生成前通过 `generate_interceptor` 插入附加设定；
- `data/abilities.json` 可继续扩充的本地数据格式；
- 数据文件读取失败时的本地降级示例。

## 安装位置

把本目录中的文件放入 SillyTavern 的 `public/scripts/extensions/third-party/ability-fusion-engine/` 文件夹，并在酒馆扩展管理器中启用。当前没有自动安装动作，也没有要求服务器插件。

## 使用

1. 打开 SillyTavern 聊天页面。
2. 在底部输入框左侧的快捷入口区域找到魔杖图标按钮。
3. 点击按钮打开独立的“外挂能力聚合引擎”面板。
4. 搜索或按分类、作品筛选。
5. 点击“加入外挂”，再打开右上角“注入开关”。
6. 下一次生成时，外挂会临时加入上下文；取消选择或关闭开关后，后续生成不再加入。

## 数据格式

每条记录至少需要：

```json
{
  "id": "stable-id",
  "category": "ability",
  "name": "名称",
  "work": "作品名",
  "source": { "status": "verified | unverified | example", "label": "来源说明", "url": null },
  "tags": ["标签"],
  "description": "面板中的短说明",
  "prompt": "真正注入给模型的说明"
}
```

`category` 只能使用 `ability`、`cultivation`、`skill`、`system`。

## 当前未验证边界

- 尚未在用户的真实 SillyTavern 实例中安装和启用；
- 面板按钮依赖酒馆聊天页的 `#leftSendForm` / `#send_form` 输入区容器；
- 当前按 SillyTavern 的生成拦截器约定，在最新用户消息之前加入附加系统消息；尚未确认目标实例的实际消息顺序和清理时机；
- 这不是精确的内部“用户设定描述后”栏位控制，具体排序需要真实宿主确认；
- 当前数据是少量示例，不代表已经完成全网资料收集。

## 安全边界

扩展不访问账号密钥，不发起外部资料请求，不调用保存聊天记录的接口。它会在生成前改动拦截器收到的消息数组，并在生成结束/回复到达事件尝试移除该临时消息；是否完全不进入持久聊天记录尚未经过真实宿主验收。扩展不自动安装其他扩展。真实安装、发布和资料收集不包含在本轮授权内。
