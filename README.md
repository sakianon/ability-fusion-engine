# 全能外挂引擎

这是一个 SillyTavern 浏览器扩展。它提供一个可编辑的外挂资料库，让用户按类型和作品选择外挂，并在生成前把选中的外挂作为临时附加设定加入上下文。

## 当前包含

- 能力、功法、技能、系统、道具五种分类；
- 作品筛选和关键词搜索；
- 类型分类与作品分类可以同时启用，筛选条件会叠加生效；
- 条目分页，默认每页显示 6 条；
- 内置条目可直接编辑或删除；
- 可一键恢复所有内置条目到原始状态，不影响自建条目；
- 用户可以通过模板新建条目，也可以编辑和删除自己创建的条目；
- 用户条目、修改覆盖和删除记录保存到 `extensionSettings.ability-fusion-engine`，不会改写仓库里的内置数据文件；
- 加入、取消、只看已选；
- 选择保存到 `extensionSettings.ability-fusion-engine`；
- 酒馆底部扩展快捷入口弹出列表中的菜单项；
- 点击菜单项后打开独立面板；
- 总注入开关；
- 生成前通过 `generate_interceptor` 插入附加设定；
- `data/works/` 按作品拆分的本地数据文件；
- `data/works-manifest.json` 内置作品文件清单，扩展启动时会自动合并加载；
- 结构化外挂详情与可选阶段变化；
- `ABILITY-DETAIL-GUIDE.md` 提供字段填写说明和可复制的详情撰写提示词；
- 内置小说、动漫能力资料。

## 安装位置

把本目录中的文件放入 SillyTavern 的 `public/scripts/extensions/third-party/ability-fusion-engine/` 文件夹，并在酒馆扩展管理器中启用。当前没有自动安装动作，也没有要求服务器插件。

## 使用

1. 打开 SillyTavern 聊天页面。
2. 点击底部原有的扩展程序快捷入口。
3. 在弹出的扩展列表里点击“全能外挂引擎”。
4. 在面板里搜索或按分类、作品筛选。
5. 点击“新建条目”打开编辑器；可以直接点击“载入设定模板”，再修改名称、作品、标签、简介、核心效果、发动方式、限制、代价和可选阶段。
6. 在条目卡片上使用“编辑”或“删除”；内置条目的修改会保存为用户覆盖，删除只对当前用户隐藏原始条目。
7. 如需撤销所有内置条目的修改，点击“恢复内置”并确认；这只清除内置覆盖和删除记录，不会删除或修改自建外挂。
8. 点击“加入外挂”，再打开右上角“注入开关”。
9. 下一次生成时，外挂会临时加入上下文；取消选择或关闭开关后，后续生成不再加入。

## 数据格式

每条记录至少需要：

```json
{
  "id": "stable-id",
  "category": "ability",
  "name": "名称",
  "work": "作品名",
  "tags": ["标签"],
  "description": "面板中的短说明",
  "effects": ["具体效果"],
  "requirements": ["发动方式"],
  "limits": ["限制、失效条件或反制方式"],
  "costs": ["消耗、冷却、风险或副作用"],
  "stages": []
}
```

`category` 只能使用 `ability`、`cultivation`、`skill`、`system`、`item`（道具）。

条目边界按“通用基础合并、专门类别分开、内部招式归回载体”处理。例如 Re:Zero 的火、水、风、土、阴、阳魔法分别收录，各系普通术式归入该系，不再用一个总条目重复授予六系能力。完整规则与可复制提示词见 `ABILITY-DETAIL-GUIDE.md`。

面板内置模板见 `data/ability-template.json`。`id` 只在直接维护 JSON 文件时需要稳定填写；面板新建条目会自动生成用户条目 ID。`requirements` 是“发动方式”的内部字段名：只说明选中该外挂后如何主动使用，或被动效果的实际触发方式，不记录如何获得外挂、谁曾持有或谁有资格使用。生成前会从外挂名称、作品、简介、效果、发动方式、限制、代价和阶段自动整理完整资料，不使用 `prompt` 字段。

用户编辑不会直接修改 `data/works/` 内置文件：

- 自定义条目保存到 `customAbilities`；
- 编辑内置条目保存到 `abilityOverrides`；
- 删除内置条目保存到 `deletedIds`；
- 选择状态仍保存到 `selectedIds`。

扩展启动时先读取 `data/works-manifest.json`，再并行读取清单中的每个作品文件，最后合并成面板使用的内置条目列表。新增作品时，添加一个作品 JSON 文件并把文件名加入清单即可；同一作品的条目应放在同一个文件中。扩展不自动迁移历史条目 ID、旧字段或拆分前的整包记录。内置条目被合并、拆分或替换后，请重新选择；旧编辑内容不保证沿用。读取设置不会因为历史数据清理而自动触发保存。

## 当前未验证边界

- 尚未在用户的真实 SillyTavern 实例中安装和启用；
- 扩展列表菜单项依赖酒馆页面的 `#extensionsMenu` / `.extensionsMenu` 容器（宿主 DOM，非稳定公共 API）；
- 当前按 SillyTavern 的生成拦截器约定，在最新用户消息之前加入附加系统消息；尚未确认目标实例的实际消息顺序和清理时机；
- 这不是精确的内部“用户设定描述后”栏位控制，具体排序需要真实宿主确认；
- 当前内置资料是持续整理结果，不代表覆盖所有作品、改编版本或所有能力条目。

## 安全边界

扩展不访问账号密钥，不发起外部资料请求，不调用保存聊天记录的接口。它会在生成前改动拦截器收到的消息数组，并在生成结束/回复到达事件尝试移除该临时消息；是否完全不进入持久聊天记录尚未经过真实宿主验收。扩展不自动安装其他扩展。真实安装、发布和资料收集不包含在本轮授权内。
